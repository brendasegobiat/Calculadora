# 🧮 Projeto Calculadora em Python

Este é um script de calculadora desenvolvido em *Python 3* como parte dos exercícios do curso. O projeto foi migrado de um script de terminal Shell (.sh) original para uma estrutura em Python altamente compatível com automações.

## 🚀 Como executar o projeto

Para rodar a calculadora no seu terminal Linux ou WSL, certifique-se de ter o Python instalado e execute:

bash
python3 calculadora.py


## 🛠️ Funcionalidades
* Soma
* Subtração
* Multiplicação
* Divisão (com proteção contra divisão por zero)
